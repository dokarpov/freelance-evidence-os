# Rilatu QA and publication status — 12 October 2026

## Product and identity
- Approved **rilatu.** wordmark traced from the image supplied by the user into `rilatu-logo.svg`: scalable SVG outlines with no embedded bitmap. Header uses the full vector; favicon uses the matching `r` contour; `og-cover.svg` uses the same paths.
- Brighter orange `#ff8048` and lighter warm paper `#fffaf6`. Archivo remains the sole UI typeface. Layout and motion foundation is otherwise stable.
- Demo changed from a dense all-at-once panel to **Choose → Inspect → Review**. Each step reveals only the relevant decision, supports Back/Next and keyboard use, and changes the underlying source facts only when the user chooses a different example.
- Static editorial rows do not react to hover like controls. Real buttons have a clear selected/expanded/result state. Public GitHub/source links were removed from the website.

## Automated tests
- `tests/site_check.py` checks that the approved vector is referenced, no obsolete arrow or repository link remains, synthetic disclaimers exist, and component/motion constraints are preserved.
- `tests/responsive.spec.js` covers Chromium viewports 320, 375, 390, 768, 1024, 1360, 1440, 1920px. The suite exercises guided stages, selection states, click/keyboard behavior, source inspection, review text, export, reduced-motion and responsive layout.

## Private repo and public hosting
- Confirmed repository visibility: **private**.
- After this change, an external unauthenticated GitHub Actions HTTP probe returned **404** for `https://dokarpov.github.io/rilatu/`. This independently confirms that the old public link is unavailable.
- The latest code is committed in the private repository, **not publicly deployed**. Do not confuse passing tests with publication.
- For a public website with private repository history, connect the repo to Netlify (prepared `netlify.toml`) or Cloudflare Pages; publish **only `dist`**, generated by `python3 scripts/build_site.py`.
- Users can always inspect shipped HTML/CSS/JS via browser devtools. A private repository does not make client-side code secret or grant patent rights.
- A new HTTPS site URL and successful unauthenticated smoke check are required before the publication gate can close.

An indicator with one-third parent width was moved using 300% of its own width per step; Germany shifted out of bounds. The corrected 100%-per-index geometry is tested. The selected active tab, content and underline remain a single state; decorative hover alone cannot change that state.
